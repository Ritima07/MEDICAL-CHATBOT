# Medical Chatbot

A chatbot that answers medical questions, built with Python and Flask.

## Features
- Chat interface for asking medical questions
- Answers generated using an AI model
- Simple and easy-to-use web page

## How to Run
1. Clone the project:
   git clone https://github.com/Ritima07/MEDICAL-CHATBOT.git
2. Go to the folder:
   cd MEDICAL-CHATBOT
3. Install the requirements:
   pip install -r requirements.txt
4. Create a `.env` file and add your API keys
5. Run the app:
   python app.py

## Disclaimer
This chatbot is for information only. It is not a substitute for professional medical advice.
